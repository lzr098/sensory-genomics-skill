## 7. 方法学与局限性

### 7.1 分析方法

| 项目 | 说明 |
|------|------|
| VCF 解析 | pysam.VariantFile 流式读取，支持 .vcf / .vcf.gz |
| 预过滤 | QUAL ≥ 30，DP ≥ 10，FILTER = PASS |
| 变异注释 | Ensembl VEP REST API（默认）或本地 VEP |
| 基因集 | 预定义五大感官子系统基因集（YAML 静态配置） |
| 功能评估 | 五级评估体系，综合蛋白影响 × 基因确定性 × 遗传模式 |
| 遗传模式 | 隐性纯合 / X-连锁 / 显性 / 线粒体 |
| API 富集 | UniProt（蛋白功能）、gnomAD（人群 AF）、ClinVar（记录）、GTEx（表达） |
| 缓存策略 | SQLite 异步缓存，TTL 30 天 |

### 7.2 已知局限

1. **CNV 未覆盖**：本分析仅检测 SNV 和短 indel（<50bp），未覆盖拷贝数变异（CNV）、大片段缺失/重复、倒位、易位等结构变异。对于 OPN1LW/OPN1MW、GJB6 等基因，CNV 是重要的致病变异类型。

2. **OR 配体不完整**：仅约 10% 的 OR 基因有明确的配体-受体对应关系，大量 OR 基因的配体未知，因此嗅觉受体缺失的表型预测存在很大不确定性。

3. **味觉多因素影响**：味觉能力受年龄、饮食习惯、吸烟、药物、口腔健康等多因素影响，TAS2R38 Haplotype 仅解释苦味感知差异的一部分。

4. **非编码变异未深入分析**：启动子、增强子、深度内含子等调控区变异可能显著影响基因表达，但当前分析主要关注编码区变异。

5. **人群参考数据库局限**：gnomAD 等数据库主要基于欧洲和东亚人群，对其他族群的参考数据有限。

6. **单样本分析的局限**：本分析基于单个个体的 VCF，无法判断复合杂合变异的相位（cis/trans），也无法进行 Trio 分析。

7. **VEP 注释的局限**：VEP 后果预测基于算法推断，部分罕见变异的实际功能影响可能与预测不符。

### 7.3 数据可用性状态
