## 2. 产品定义

### 2.1 Product Goals（3个）

1. **提供可解释的感官基因功能评估**：基于个体基因组变异，对每个感官子系统（五感）进行功能影响程度分级（完全丧失 → 无影响），以非诊断性语言向用户呈现可理解的基因层面感官特征。

2. **支撑科研与健康管理场景**：为遗传学研究、个人基因组解读、健康管理等场景提供标准化的感官基因分析报告，输出包含 Markdown 人类可读报告和 JSON 机器可读结构化数据。

3. **遵循医学伦理与合规边界**：通过强制免责声明、禁用诊断性词汇、限制未成年人预测、对高风险基因结果建议遗传咨询等机制，确保产品不做医学诊断、不替代临床检查。

### 2.2 User Stories（5个）

1. **作为**一位完成了全基因组测序的个人用户，**我想**上传我的 VCF 文件并获得一份五官感官能力的基因分析报告，**以便**了解我在色觉、听觉、嗅觉、味觉、痛觉等方面的基因层面特征。

2. **作为**一位遗传学研究者，**我想**获取 VCF 中所有落在感官基因集上的变异及其功能影响评估（含结构化 JSON），**以便**将感官基因变异数据纳入我的研究分析管线。

3. **作为**一位关注健康的用户，**我想**知道我的 TAS2R38 基因型组合（如 PAV/AVI），**以便**理解我对苦味的感知能力差异。

4. **作为**一位有已知色弱家族史的用户，**我想**了解我的 OPN1LW/MW 基因变异情况，**以便**知道 SNV 层面的发现，同时明确了解 CNV/重组分析的局限性。

5. **作为**一位想了解药物风险的用户，**我想**知道我的线粒体 MT-RNR1 基因是否携带氨基糖苷类致聋相关变异，**以便**在使用相关抗生素时提高警惕。

## 3. 技术规范

### 3.1 Requirements Pool（需求池）

#### P0 — MVP 必须有的功能

| ID | 需求描述 | 验收标准 |
|----|---------|---------|
| P0-01 | **VCF 输入解析与质控过滤** | 能正确解析 `.vcf` / `.vcf.gz` 的 GT/DP/GQ/QUAL 字段；过滤 QUAL<30、DP<10、非 PASS 的变异 |
| P0-02 | **VEP 变异注释** | 支持 Ensembl VEP REST API 或本地 VEP；获取 HGVSc/HGVSp/Consequence/Protein domains 等核心注释 |
| P0-03 | **感官基因集加载与变异筛选** | 加载预定义的五大感官子系统基因集（视觉/听觉/嗅觉/味觉/体感），仅保留落在这些基因上的变异；保留所有后果类型（含同义，用于完整性检查） |
| P0-04 | **功能影响评估体系** | 实现五级评估：完全丧失 / 显著影响 / 部分影响 / 可能轻微影响 / 无影响；综合蛋白功能影响 × 基因功能确定性 × 遗传模式匹配 |
| P0-05 | **遗传模式匹配判定** | 支持隐性（纯合/复合杂合）、X-连锁（男性半合子/女性纯合/杂合）、显性、线粒体四种模式的基因型-表型匹配判断 |
| P0-06 | **五感 Markdown 报告生成** | 按视觉/听觉/嗅觉/味觉/体感五章组织；每章包含基因卡片（变异信息 + 感官影响评估 + 影响依据 + 遗传模式）；含执行摘要 |
| P0-07 | **JSON 结构化输出** | 输出包含全部变异、评估结果、元数据的机器可读 JSON |
| P0-08 | **强制免责声明** | 报告首页必须包含标准免责声明；禁止出现"致病""患者"等诊断性词汇 |
| P0-09 | **输入参数支持** | 必需：VCF 文件路径、样本性别（M/F）；可选：分析子系统子集、已知表型文本 |
| P0-10 | **特殊基因基础处理** | OR 基因：纯合 LoF → "完全丧失"，杂合不展示；OPN1LW/MW：仅 SNV 分析并标注 CNV 局限；TRPV1/TRPM8：错义默认"可能轻微影响" |

#### P1 — v0.1.0 建议有的功能

| ID | 需求描述 | 验收标准 |
|----|---------|---------|
| P1-01 | **TAS2R38 Haplotype 分析器** | 能正确判定 rs713598/rs1726866/rs10246939 三个 SNP 的组合 diplotype（PAV/AVI/AAI 等），输出苦味感知能力评估 |
| P1-02 | **OR 基因分级展示** | Tier A（已知配体 + 纯合 LoF/显著错义）正文详细展示；Tier B（功能研究但配体未知 + 纯合 LoF）表格列出；Tier C（其余纯合 LoF）附录折叠 |
| P1-03 | **线粒体耳聋注释器** | 识别 MT-RNR1/MT-TS1 已知位点（如 m.1555A>G），输出药物风险警告；展示异质性水平（若 VCF 包含） |
| P1-04 | **蛋白拓扑位置分析** | 报告展示变异所在的蛋白拓扑位置（跨膜域 / 胞外环 / 胞内域 / 配体结合口袋等） |
| P1-05 | **API 富集（异步）** | 并发查询 UniProt（蛋白功能/域/拓扑）、GTEx（感官组织表达）、gnomAD（人群 AF）、ClinVar（记录）；仅作信息展示，不参与评估 |
| P1-06 | **本地缓存策略** | SQLite 缓存 API 查询结果，TTL 30 天；含速率限制处理（Ensembl 15 req/s，NCBI 3 req/s） |
| P1-07 | **参考信息展示区** | 每个基因卡片包含 gnomAD AF / ClinVar / SpliceAI / CADD 信息区（可配置开关）；当数据不可用时明确标注 |
| P1-08 | **方法学与局限性章节** | 报告包含分析方法说明、已知局限列表（CNV 未覆盖、OR 配体不完整、味觉多因素影响等） |

#### 3.2.2 基因卡片固定字段

每个基因卡片必须包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| 基因名 + 感官功能 | 文本 | 基因在感官系统中的作用描述 |
| 变异基本信息 | 表格 | chr:pos, ref>alt, HGVSc, HGVSp, GT, DP, QUAL |
| **感官影响评估** | 标签 | 完全丧失 / 显著影响 / 部分影响 / 可能轻微影响 / 无影响 |
| 影响依据 | 文本 | 评估逻辑说明（蛋白影响 + 遗传模式 + 基因确定性） |
| 遗传模式 | 文本 | 隐性纯合 / 隐性复合杂合 / X-连锁 / 显性 / 线粒体 |
| 蛋白位置 | 文本 | 拓扑位置（跨膜域 / 胞外环 / 胞内域 / 配体结合口袋等） |
| 结构影响 | 文本 | 对蛋白结构的预测影响 |
| NMD 预测 | 文本 | 是否触发无义介导降解 |
| 参考信息展示区 | 表格 | gnomAD AF / ClinVar / SpliceAI / CADD（仅展示，可配置） |
| 综合判断 | 文本 | 对个体感官能力的意义描述 |
| 局限说明（可选） | 文本 | 该基因/变异的特殊分析局限 |

#### 3.2.3 执行摘要感官概览表格式

| 感官系统 | 完全丧失 | 显著影响 | 部分影响 | 可能轻微影响 | 无影响 | 关键发现摘要 |
|---------|---------|---------|---------|-------------|--------|------------|
| 视觉 | 0 | 0 | 1 | 2 | — | OPN1LW 错义（色觉光谱偏移） |
| 听觉 | 0 | 0 | 0 | 0 | — | 未发现影响变异 |
| 嗅觉 | 3 | 0 | 5 | — | — | OR2B11/2T11/7D4 完全丧失 |
| 味觉 | 0 | 0 | 1 | — | — | TAS2R38 AVI/AVI（苦味不敏感） |
| 触觉痛觉 | 0 | 0 | 0 | 0 | — | 未发现影响变异 |

## 5. 验收标准（Acceptance Criteria）

- [ ] 能从 VCF 文件正确解析 GT/DP/QUAL，过滤低质量变异
- [ ] 能正确识别落在感官基因集上的所有变异（包括同义）
- [ ] 能正确评估 GJB2 纯合 frameshift 为"显著影响 — 听觉功能受损"
- [ ] 能正确评估 OR 基因纯合 frameshift 为"完全丧失 — 特定嗅觉受体缺失"（非致病）
- [ ] 能正确判定 TAS2R38 三个 SNP 的组合 haplotype（PAV/AVI/AAI 等）
- [ ] 能正确标注线粒体 MT-RNR1 m.1555A>G 并附加药物警告
- [ ] 报告中 ClinVar/gnomAD/SpliceAI/CADD 仅出现在"参考信息展示"区
- [ ] 报告包含蛋白拓扑位置分析（跨膜域 / 胞外环 / 胞内域）
- [ ] 报告包含免责声明和遗传咨询建议
- [ ] 色觉基因章节包含"CNV 未覆盖"的明确局限说明
- [ ] 输出包含 Markdown 报告 + JSON 结构化数据
- [ ] 单样本分析时间（有缓存）< 5 分钟
